# 资料口径

全部主体和观测均为本地合成资料，不代表企业、个人或真实设备。编号只在资料包内有意义，金额为人民币元，时刻统一为带 +08:00 的北京时间。空单元表示未知或不适用，不等于零；真假值用 true/false；数值不含千位分隔。CSV 行顺序不表示业务先后。时间区间采用左闭右开，除非字段说明另有规定。

示范试验的 effect 为每单位相同服务量的购能变化，不同 metric 的数字不能直接合并。application 包含总体中的未核实设备，selection_probability 为空表示机会机制未知，0 表示从未覆盖；不能自动填成小概率。site_profile 与 evidence 的压力、负荷、电网条件决定可比较范围，字段不是模型特征答案。stage 的 predecessors 分号分隔是工程前提，boundary_change 是前提完成后对公用工程条件的事实调整，非已知节能效果。同一 evidence_group 的效果有共同不确定性。started 的开工成本不可撤回。
evidence.effect 是已给研究摘要而非本应用计算答案；randomized_cluster 和 before_after 的可解释性不同。stderr 仅为摘要标准误，evidence_group 相同的相关性未给定，不得默认为独立。boundary_change 影响后续阶段的适用汽源，不能改变已开工设备当时依据。精度 precision 是追加本地验证预计标准误，实际返回可与之不同。slots 是扣除当前已开工占用后的剩余容量，当前开工成本已经发生且不可撤销，预算是此刻剩余预算。

## evidence
示范试验观察，metric 与基准服务量明确，保留共同批。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| evidence_id | string | 证据 |
| evidence_group | string | 共同试验批 |
| technology | string | 技术 |
| steam_source | string | 蒸汽来源 |
| load | number | 负荷 |
| grid_kg | number | 电力排放因子 |
| metric | string | 效果口径 |
| effect | number | 服务单位购能变化 |
| stderr | number | 不确定尺度 |
| available_at | datetime | 可知 |
| design | string | 示范研究安排 |
| comparison | string | 效果参照 |
| service_definition | string | 服务单位定义 |

记录键：evidence_id。

## sites

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| site_id | string | 厂区 |
| steam_source | string | 蒸汽来源 |
| load_min | number | 负荷下界 |
| load_max | number | 负荷上界 |
| grid_kg | number | 电力排放因子 |
| window | string | 停机窗口 |

记录键：site_id。

## applications
包括未核实的设备总体与申报机会资料。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| device_id | string | 设备 |
| site_id | string | 厂区 |
| technology | string | 技术 |
| service_units | number | 服务规模 |
| reported_saving | number | 申报节约 |
| selection_reason | string | 核实原因 |
| selection_probability | number | 抽中概率 |
| verified | boolean | 已核实 |

记录键：device_id。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| verification_id | string | 核实 |
| device_id | string | 设备 |
| actual_load | number | 负荷 |
| steam_source | string | 实际汽源 |
| meter_error | number | 测量误差 |
| available_at | datetime | 可知 |

记录键：verification_id。

## stages

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| stage_id | string | 阶段 |
| site_id | string | 厂区 |
| device_ids | string | 设备编号分号分隔 |
| predecessors | string | 前提阶段 |
| cost | number | 费用 |
| window | string | 窗口 |
| status | string | proposal或started |
| boundary_change | string | 完成后的汽源变化 |

记录键：stage_id。

## windows
验证和工程共同占用的停机窗口。slot 是本周期剩余名额。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| window | string | 窗口 |
| slots | integer | 剩余名额 |
| delay_cost | number | 延后一期损失 |
| budget | number | 可用预算 |

记录键：window。

## local_options
可选择的本地验证，group 相同可以共同减少一类证据缺口但不是独立样本。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| option_id | string | 核实选项 |
| site_id | string | 厂区 |
| device_id | string | 设备 |
| window | string | 窗口 |
| slot_usage | integer | 窗口占用 |
| cost | number | 成本 |
| precision | number | 预期误差 |
| group | string | 共同来源 |

记录键：option_id。

| actual_source | string | 本地汽源 |

| effect | number | 本地估计效果 |
